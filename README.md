# Yiğit Alemdar — Kişisel Portföy

Bağımlılık gerektirmeyen, mobil uyumlu kişisel portföy sitesi.

## Çalıştırma

`index.html` dosyasını tarayıcıda açın. Yerel sunucu tercih ederseniz:

```powershell
python -m http.server 8000
```

Ardından `http://localhost:8000` adresini ziyaret edin.

## Kişiselleştirme

- Metinler, proje adları ve bağlantılar: `index.html`
- Renkler ve görünüm: `styles.css` dosyasının başındaki değişkenler
- Tema ve kaydırma animasyonları: `script.js`

`href="#"` olan proje ve sosyal medya bağlantılarını kendi adreslerinizle değiştirin.
